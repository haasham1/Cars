# AutoDrive 🚗

A modern vehicle listing dashboard built with React, TypeScript, and Tailwind CSS.

## Getting Started


### Install & Run

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

### Build for Production

```bash
npm run build
```

---



## Features

- Vehicle listing with search, sort, and filters (brand, price range, stock)
- Debounced search (500ms)
- Client-side pagination (10 per page) with numbered page buttons
- Vehicle detail modal on card click
- Active filter pills with individual clear buttons
- Responsive grid (1 → 2 → 3 → 4 → 5 columns)
